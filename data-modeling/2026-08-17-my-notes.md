## OLTP vs OLAP

OLTP vs OLAP --> OLTP is for transactional modeling, in here we care more about how each transaction is saved, so the modeling should focus mainly on txns, how we save them, how we save cost. This is mostly just adding records to existing data (should choose cheapest storage option for this layer)

OLAP - Online analytical processing --> OLAP is built specifically for analytical purposes, hence should be more detauled as to how the data flows, normalizations, business dashboards etc.,
